RESUME / CV
===========

Put your resume PDF in THIS folder and name it exactly:

    Loh-Jinn-Yip-Resume.pdf

Full path:
    public/resume/Loh-Jinn-Yip-Resume.pdf

The "Download Resume" button in the hero links to /resume/Loh-Jinn-Yip-Resume.pdf
and downloads it automatically when clicked. As soon as you drop the PDF here
with that exact name, the button works — no code changes needed.

Tips:
- Keep the file name exactly as above (case-sensitive, hyphens, no spaces).
- If you want a different file name, update the `href` and `download` values in
  src/components/Hero.jsx to match.
- Keep the PDF reasonably small (ideally under ~5 MB) so it downloads fast and
  stays git-friendly.
